# Phishing Email Detection Model

## Overview

This project uses Machine Learning and Scikit-learn to classify emails as Phishing or Safe.

## Features

* Email text analysis
* Phishing keyword detection
* TF-IDF feature extraction
* Email classification using Naive Bayes
* Accuracy score
* Confusion matrix

## Technologies Used

* Python
* Pandas
* Scikit-learn

## Files

* emails.csv
* phishing_detector.py

## Output

The model predicts whether an email is:

* Phishing
* Safe
